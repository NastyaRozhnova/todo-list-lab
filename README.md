# To-Do List

Лабораторная работа: веб-приложение для управления задачами.

## Возможности

- Добавление задач с названием и необязательным сроком.
- Редактирование названия и даты.
- Удаление задач.
- Отметка выполнения с зачёркиванием названия.
- Перемещение задачи в конец ручного порядка при выполнении.
- Поиск по названию.
- Фильтрация по статусу и конкретной дате.
- Сортировка по сроку: сначала ближайшие или поздние даты.
- Изменение порядка задач перетаскиванием мышью.
- Перемещение на телефоне после удержания карточки.
- Сохранение задач и ручного порядка в localStorage.
- Адаптивное оформление для компьютеров и телефонов.
- Сохранение поиска, фильтров и сортировки после перезагрузки.

## Технологии

HTML5, CSS3, JavaScript, DOM API, localStorage.

JS- и CSS-фреймворки, сторонние библиотеки и сборщик не используются.

В исходном HTML находится базовый каркас, подключение favicon и скрипта.

## Как работает порядок задач

Приложение запоминает порядок задач и восстанавливает его после перезагрузки страницы.

Можно отсортировать задачи по дате, а затем выбрать «Ручной порядок», чтобы вернуться к своей последовательности. При сортировке задачи без срока показываются в конце.

В режиме «Ручной порядок» задачи можно перетаскивать, даже если включены поиск или фильтры. Порядок меняется только у показанных задач. Скрытые задачи остаются на своих местах.

Чтобы поставить задачу перед другой, перетащите её на верхнюю половину той карточки. Чтобы поставить после — на нижнюю.

На телефоне сначала удерживайте карточку примерно полсекунды, затем тяните её на нужное место. Для прокрутки страницы двигайте палец без удержания.

Когда вы отмечаете задачу выполненной, она перемещается в конец ручного списка. При включённой сортировке по дате она остаётся на месте, которое соответствует её сроку.

## Хранение данных

Задачи сохраняются в localStorage под ключом todo-list-lab:tasks: идентификатор, название, дата и статус выполнения. Задачи сохраняются в том порядке, в котором вы их расположили.

Поиск, фильтры и сортировка сохраняются под ключом todo-list-lab:filters и восстанавливаются после перезагрузки. Кнопка «Сбросить фильтры и сортировку» возвращает стандартные настройки и сохраняет их.
